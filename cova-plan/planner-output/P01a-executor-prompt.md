```markdown
You review every Supabase migration PR for safety. You are invoked by the
GitHub Action `.github/workflows/schema-review.yml` on PRs that touch
`supabase/migrations/**`. You produce a PR comment via the `gh` CLI.

## Read order

1. The PR diff: every `*.sql` file under `supabase/migrations/`
2. The paired `_down.sql` if present
3. `cova-plan/OPEN_DECISIONS.md` (especially D-022, Decision 5, Decision 10)
4. `cova-plan/PHASE_STATUS.md` to identify which phase the migration belongs to
5. Live Supabase schema via Supabase MCP (snapshot of pre-merge state)

## Checklist

For each migration file:

1. **Idempotency.** Does it use `IF NOT EXISTS`, `IF EXISTS`, `ON CONFLICT DO
   NOTHING`? If not, would re-running break? FAIL otherwise.
2. **Paired _down.sql.** Does a corresponding `_down.sql` exist with the
   reverse operation? FAIL otherwise.
3. **RLS on new tables.** Every CREATE TABLE must be followed by `ALTER TABLE
   ... ENABLE ROW LEVEL SECURITY` either in the same file or in the next
   migration in ordering. FAIL otherwise.

   prefixed `p{N}_` matching the owning phase. P01a uses `p1_`. FAIL otherwise.
5. **No naming collisions.** Migration filenames must be unique timestamps;
   policy names, index names, table names must not collide with existing
   identifiers (cross-check Supabase MCP).
6. **Index naming convention.** Indexes on FK columns named `idx_{table}_{col}`
   or `{table}_{col}_idx`. Composite: `idx_{table}_{col1}_{col2}`. WARN
   otherwise (not FAIL).
7. **Data-loss declarations.** Any DROP TABLE or DROP COLUMN must include a
   SQL comment block stating the row-count being lost (cross-check via MCP).
8. **CASCADE awareness.** DROP TABLE ... CASCADE must list the dependent
   objects in a SQL comment so reviewers can see the blast radius.
```

### C.6 `scripts/sync-subagents.sh` (executable; chmod 755)

```bash
#!/usr/bin/env bash
# scripts/sync-subagents.sh
# Syncs cova-plan/subagents/*.md → .claude/agents/*.md.
# Usage:
#   ./scripts/sync-subagents.sh         # apply
#   ./scripts/sync-subagents.sh --check # verify in sync; exit 1 if drift (CI)
set -euo pipefail

SRC_DIR="cova-plan/subagents"
DEST_DIR=".claude/agents"

if [[ ! -d "$SRC_DIR" ]]; then
  echo "ERROR: $SRC_DIR does not exist" >&2
  exit 1
fi

mkdir -p "$DEST_DIR"

MODE="apply"
if [[ "${1:-}" == "--check" ]]; then
  MODE="check"
fi

DRIFT=0
for src in "$SRC_DIR"/*.md; do
  name="$(basename "$src")"
  dest="$DEST_DIR/$name"
  if [[ ! -f "$dest" ]]; then
    if [[ "$MODE" == "check" ]]; then
      echo "DRIFT: $dest missing"
      DRIFT=1
    else
      cp "$src" "$dest"
      echo "synced: $name (created)"
    fi
    continue
  fi
  if ! diff -q "$src" "$dest" > /dev/null; then
    if [[ "$MODE" == "check" ]]; then
      echo "DRIFT: $dest differs from $src"
      DRIFT=1
    else
      cp "$src" "$dest"
      echo "synced: $name (updated)"
    fi
  fi
done

if [[ "$MODE" == "check" && "$DRIFT" -eq 1 ]]; then
  echo "Run ./scripts/sync-subagents.sh to fix." >&2
  exit 1
fi

echo "OK"
```

```typescript
// Reads the migration files from the PR diff, calls Anthropic Sonnet with
// cova-plan/subagents/schema-reviewer.md as the system prompt, posts a PR
// comment via the gh CLI.

import Anthropic from "@anthropic-ai/sdk";
import { execSync } from "node:child_process";
import { readFileSync, existsSync } from "node:fs";
import { join } from "node:path";

const PR_NUMBER = process.env.PR_NUMBER;
const ANTHROPIC_API_KEY = process.env.ANTHROPIC_API_KEY;
const REPO = process.env.GITHUB_REPOSITORY ?? "pgoel813/cova";

if (!PR_NUMBER) {
  console.error("PR_NUMBER not set");
  process.exit(1);
}
if (!ANTHROPIC_API_KEY) {
  console.error("ANTHROPIC_API_KEY not set");
  process.exit(1);
}

const systemPrompt = readFileSync(
  "cova-plan/subagents/schema-reviewer.md",
  "utf8",
);

const changedFiles = execSync(
  `gh pr diff ${PR_NUMBER} --name-only`,
  { encoding: "utf8" },
)
  .split("\n")
  .map((s) => s.trim())
  .filter((p) => p.startsWith("supabase/migrations/") && p.endsWith(".sql"));

if (changedFiles.length === 0) {
  console.log("No migration files in PR; skipping.");
  process.exit(0);
}

const fileBlobs = changedFiles
  .map((p) => {
    const exists = existsSync(p);
    if (!exists) return `## ${p}\n\n(deleted)\n`;
    const body = readFileSync(p, "utf8");
    return `## ${p}\n\n\`\`\`sql\n${body}\n\`\`\`\n`;
  })
  .join("\n---\n");

const userPrompt = `Review the following migration file(s) per your checklist.
Report findings in markdown table form for a GitHub PR comment. Be concise but
specific (file:line for any issue). Conclude with overall verdict (PASS /
PARTIAL / FAIL).

${fileBlobs}`;

const client = new Anthropic({ apiKey: ANTHROPIC_API_KEY });
const resp = await client.messages.create({
  model: "claude-sonnet-4-5",
  max_tokens: 4000,
  temperature: 0,
  system: systemPrompt,
  messages: [{ role: "user", content: userPrompt }],
});

const reportText = resp.content
  .filter((b) => b.type === "text")
  .map((b: any) => b.text)
  .join("\n");

const verdict = /Overall:\s*(PASS|PARTIAL|FAIL)/i.exec(reportText)?.[1] ?? "PARTIAL";
const failing = verdict.toUpperCase() !== "PASS";

execSync(
  `gh pr comment ${PR_NUMBER} --body ${JSON.stringify(reportText)}`,
  { stdio: "inherit" },
);

if (failing) process.exit(1);
process.exit(0);
```

### C.8 `scripts/agents/cost-monitor.ts`

```typescript
#!/usr/bin/env tsx
// scripts/agents/cost-monitor.ts
// Invoked by Vercel Cron via apps/web/app/api/cron/cost-monitor/route.ts.
// Standalone version for local dry-runs.

import Anthropic from "@anthropic-ai/sdk";
import { createClient } from "@supabase/supabase-js";
import { readFileSync } from "node:fs";

const SUPABASE_URL = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const SUPABASE_SERVICE_KEY = process.env.SUPABASE_SERVICE_ROLE_KEY!;
const ANTHROPIC_API_KEY = process.env.ANTHROPIC_API_KEY!;
const SLACK_WEBHOOK_URL = process.env.SLACK_WEBHOOK_URL;
const POSTHOG_KEY = process.env.NEXT_PUBLIC_POSTHOG_KEY;
const POSTHOG_HOST = process.env.NEXT_PUBLIC_POSTHOG_HOST ?? "https://eu.posthog.com";
const LAUNCH_DATE = process.env.COVA_LAUNCH_DATE ?? "2026-05-15"; // update at deploy

export async function runCostMonitor(): Promise<{
  ok: boolean;
  reportMarkdown: string;
  tripped: boolean;
  total: number;
  ceiling: number;
}> {
  const supabase = createClient(SUPABASE_URL, SUPABASE_SERVICE_KEY, {
    auth: { persistSession: false },
  });

  // 1. Pull last 24h
  const since = new Date(Date.now() - 24 * 60 * 60 * 1000).toISOString();
  const { data: rows, error } = await supabase
    .from("render_cost_log")
    .select("category, cost_usd, model, stage, duration_ms, failure_category, created_at")
    .gte("created_at", since);

  if (error) {
    return {
      ok: false,
      reportMarkdown: `# Cost report — error\n\n${error.message}`,
      tripped: false,
      total: 0,
      ceiling: 0,
    };
  }

  const total = (rows ?? []).reduce((s, r) => s + Number(r.cost_usd ?? 0), 0);

  // 2. Determine ceiling
  const launchMs = new Date(LAUNCH_DATE).getTime();
  const daysSinceLaunch = Math.floor((Date.now() - launchMs) / 86_400_000);
  let ceiling = 30;
  if (daysSinceLaunch > 7) {
    const sinceWeek = new Date(Date.now() - 7 * 86_400_000).toISOString();
    const { data: weekRows } = await supabase
      .from("render_cost_log")
      .select("cost_usd, created_at")
      .gte("created_at", sinceWeek);
    const weekTotal = (weekRows ?? []).reduce((s, r) => s + Number(r.cost_usd ?? 0), 0);
    ceiling = (weekTotal / 7) * 2;
  }
  const tripped = total > ceiling;

  // 3. Per-category aggregation
  const byCat: Record<string, { cost: number; n: number }> = {};
  for (const r of rows ?? []) {
    const k = r.category ?? "unknown";
    if (!byCat[k]) byCat[k] = { cost: 0, n: 0 };
    byCat[k].cost += Number(r.cost_usd ?? 0);
    byCat[k].n += 1;
  }
  const catRows = Object.entries(byCat)
    .sort((a, b) => b[1].cost - a[1].cost)
    .map(([k, v]) => `| ${k} | $${v.cost.toFixed(4)} | ${v.n} | $${(v.cost / Math.max(v.n, 1)).toFixed(4)} |`)
    .join("\n");

  // 4. Optional Anthropic narration
  let narration = "(narration disabled)";
  try {
    const sys = readFileSync("cova-plan/subagents/cost-monitor.md", "utf8");
    const client = new Anthropic({ apiKey: ANTHROPIC_API_KEY });
    const resp = await client.messages.create({
      model: "claude-haiku-4-5-20251001",
      max_tokens: 500,
      temperature: 0,
      system: sys,
      messages: [
        {
          role: "user",
          content: `Day total $${total.toFixed(2)}, ceiling $${ceiling.toFixed(2)}, tripped=${tripped}. Per-category JSON: ${JSON.stringify(byCat)}. Write a 3-bullet "Notable spikes" markdown section, no preamble.`,
        },
      ],
    });
    narration = resp.content
      .filter((b) => b.type === "text")
      .map((b: any) => b.text)
      .join("\n");
  } catch (e: any) {
    narration = `(narration failed: ${e?.message ?? "unknown"})`;
  }

  const today = new Date().toISOString().slice(0, 10);
  const md = `# Cost report — ${today}

Total: $${total.toFixed(4)} | Ceiling: $${ceiling.toFixed(2)} (${tripped ? "🔴 BREACH" : "🟢 OK"})
Days since launch: ${Math.max(daysSinceLaunch, 0)}

## By category
| Category | Cost | Calls | Avg/call |
|----------|------|-------|----------|
${catRows || "| (none) | $0 | 0 | $0 |"}

## Notable spikes
${narration}
`;

  // 5. Side effects
  if (tripped && POSTHOG_KEY) {
    try {
      await fetch(`${POSTHOG_HOST}/i/v0/e/`, {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({
          api_key: POSTHOG_KEY,
          event: "cost_alert",
          distinct_id: "system-cron",
          properties: { date: today, total, ceiling, top_category: Object.keys(byCat)[0] ?? null },
        }),
      });
    } catch {}
  }
  if (tripped && SLACK_WEBHOOK_URL) {
    try {
      await fetch(SLACK_WEBHOOK_URL, {
        method: "POST",
        headers: { "content-type": "application/json" },
        body: JSON.stringify({ text: `🔴 Cova cost alert — $${total.toFixed(2)} > $${ceiling.toFixed(2)} on ${today}` }),
      });
    } catch {}
  }

  // 6. Persist report to Supabase storage
  try {
    await supabase.storage
      .from("cost-reports")
      .upload(`${today}.md`, new Blob([md], { type: "text/markdown" }), { upsert: true });
  } catch {}

  return { ok: true, reportMarkdown: md, tripped, total, ceiling };
}

if (import.meta.url === `file://${process.argv[1]}`) {
  runCostMonitor().then((r) => {
    console.log(r.reportMarkdown);
    process.exit(r.ok ? 0 : 1);
  });
}
```

```typescript
import { createHash } from "node:crypto";

const EMAIL_RE = /[A-Z0-9._%+-]+@[A-Z0-9.-]+\.[A-Z]{2,}/gi;
const PHONE_RE = /\+?\d[\d\s\-().]{7,}\d/g; // crude E.164-ish
const ADDRESS_RE = /\b\d{1,5}\s+[A-Za-z0-9.\s]+(?:Street|St|Avenue|Ave|Boulevard|Blvd|Road|Rd|Lane|Ln|Drive|Dr|Court|Ct|Way)\b/gi;

const FORBIDDEN_KEYS = new Set<string>([
  "password",
  "apiKey",
  "accessToken",
  "refreshToken",
  "secretKey",
  "creditCard",
  "cvv",
  "ssn",
  "dob",
  "authToken",
  "magicLinkToken",
]);

const TRANSFORM_KEYS: Record<string, (v: unknown) => unknown> = {
  userId: (v) => (typeof v === "string" ? createHash("sha256").update(v).digest("hex").slice(0, 8) : "[invalid]"),
  sessionId: () => "[redacted]",
  ipAddress: () => "[redacted]",
  userAgent: (v) => (typeof v === "string" ? v.slice(0, 64) : "[invalid]"),
};

const redactString = (s: string): string =>
  s
    .replace(EMAIL_RE, "[email]")
    .replace(PHONE_RE, "[phone]")
    .replace(ADDRESS_RE, "[address]");

export function redactLogPayload<T>(input: T): T {
  if (input == null) return input;
  if (typeof input === "string") return redactString(input) as unknown as T;
  if (typeof input !== "object") return input;
  if (Array.isArray(input)) return input.map((x) => redactLogPayload(x)) as unknown as T;

  const out: Record<string, unknown> = {};
  for (const [k, v] of Object.entries(input as Record<string, unknown>)) {
    if (FORBIDDEN_KEYS.has(k)) {
      out[k] = "[redacted]";
      continue;
    }
    if (k in TRANSFORM_KEYS) {
      out[k] = TRANSFORM_KEYS[k](v);
      continue;
    }
    out[k] = redactLogPayload(v);
  }
  return out as T;
}

export const _internals = { EMAIL_RE, PHONE_RE, ADDRESS_RE, FORBIDDEN_KEYS, TRANSFORM_KEYS };
```

#### `apps/web/eslint-rules/no-unsafe-console.js` (CommonJS so ESLint 8 flat-rule registration works)

```javascript
// apps/web/eslint-rules/no-unsafe-console.js
// Flags console.{error,log,warn,info,debug} calls whose arguments contain
// any Identifier or ObjectExpression NOT wrapped in `redactLogPayload(...)`.
// Allows literal strings + template literals with no interpolations.

module.exports = {
  meta: {
    type: "problem",
    docs: { description: "console.* of objects must use redactLogPayload" },
    schema: [],
    messages: {
      unsafe: "console.{{method}} called with potentially sensitive value at argument {{idx}}; wrap in redactLogPayload(...)",
    },
  },
  create(context) {
    const isLogMethod = (callee) =>
      callee &&
      callee.type === "MemberExpression" &&
      callee.object?.type === "Identifier" &&
      callee.object.name === "console" &&
      callee.property?.type === "Identifier" &&
      ["error", "log", "warn", "info", "debug"].includes(callee.property.name);

    const isWrappedInRedact = (arg) =>
      arg.type === "CallExpression" &&
      ((arg.callee.type === "Identifier" && arg.callee.name === "redactLogPayload") ||
        (arg.callee.type === "MemberExpression" &&
          arg.callee.property?.type === "Identifier" &&
          arg.callee.property.name === "redactLogPayload"));

    const isSafe = (arg) => {
      if (arg.type === "Literal") return true;
      if (arg.type === "TemplateLiteral" && arg.expressions.length === 0) return true;
      if (isWrappedInRedact(arg)) return true;
      return false;
    };

    return {
      CallExpression(node) {
        if (!isLogMethod(node.callee)) return;
        node.arguments.forEach((arg, idx) => {
          if (isSafe(arg)) return;
          if (arg.type === "Identifier" || arg.type === "ObjectExpression" || arg.type === "ArrayExpression" || arg.type === "MemberExpression" || arg.type === "TemplateLiteral") {
            context.report({
              node: arg,
              messageId: "unsafe",
              data: { method: node.callee.property.name, idx: String(idx) },
            });
          }
        });
      },
    };
  },
};
```

#### `apps/web/lib/paid/call.ts`

```typescript
import { logCost } from "../cost/log";
import type { CostCategory } from "../cost/categories";

export interface PaidCallOpts {
  provider: "anthropic" | "fal" | "modal" | "searchapi" | "resend";
  url: string;
  init: RequestInit;
  costEstimate: {
    category: CostCategory;
    costUsd: number;
    model?: string;
    stage?: string;
  };
  /** Optional override for failure_category if the call fails before parse */
  failureCategoryOverride?: string;
}

export async function paidCall<T = unknown>(opts: PaidCallOpts): Promise<T> {
  const start = Date.now();
  let res: Response | null = null;
  let parsed: T | null = null;
  let failure: string | null = null;
  try {
    res = await fetch(opts.url, opts.init);
    if (!res.ok) {
      failure = opts.failureCategoryOverride ?? `cost.paidcall.fetch_fail`;
      throw new Error(`${opts.provider} ${res.status}: ${await res.text().catch(() => "")}`);
    }
    parsed = (await res.json()) as T;
    return parsed;
  } catch (e: any) {
    if (!failure) failure = `cost.paidcall.parse_fail`;
    throw e;
  } finally {
    // logCost runs even on failure
    void logCost({
      category: opts.costEstimate.category,
      stage: opts.costEstimate.stage,
      cost_usd: opts.costEstimate.costUsd,
      model: opts.costEstimate.model,
      duration_ms: Date.now() - start,
      failure_category: failure ?? null,
    });
  }
}
```

```javascript
// Forbids fetch() calls with literal URLs targeting paid providers.
// Exempts the wrapper file itself.

const FORBIDDEN_HOSTS = ["api.anthropic.com", "fal.run", "modal.run", "searchapi.io", "api.resend.com"];

module.exports = {
  meta: {
    type: "problem",
    docs: { description: "paid provider fetch() must go through paidCall()" },
    schema: [],
    messages: { direct: "fetch('{{host}}') outside lib/paid/call.ts; use paidCall()." },
  },
  create(context) {
    const filename = context.getFilename();
    if (filename.includes("apps/web/lib/paid/call.ts")) return {};

    const isForbiddenUrl = (s) => FORBIDDEN_HOSTS.some((h) => s.includes(h));
    const checkArg = (arg, node) => {
      if (!arg) return;
      if (arg.type === "Literal" && typeof arg.value === "string" && isForbiddenUrl(arg.value)) {
        const matched = FORBIDDEN_HOSTS.find((h) => arg.value.includes(h));
        context.report({ node, messageId: "direct", data: { host: matched } });
      } else if (arg.type === "TemplateLiteral") {
        const merged = arg.quasis.map((q) => q.value.cooked ?? "").join("");
        if (isForbiddenUrl(merged)) {
          const matched = FORBIDDEN_HOSTS.find((h) => merged.includes(h));
          context.report({ node, messageId: "direct", data: { host: matched } });
        }
      }
    };

    return {
      CallExpression(node) {
        if (node.callee?.type === "Identifier" && node.callee.name === "fetch") {
          checkArg(node.arguments[0], node);
        }
      },
    };
  },
};
```

### E.6 EXIF strip pipeline + test

#### `apps/web/lib/capture/process.ts`

```typescript
import sharp from "sharp";

export interface ProcessedImage {
  buffer: Buffer;
  width: number;
  height: number;
  byteLength: number;
}

/**
 * Strip EXIF, normalize orientation, downscale to ≤1536px on longest edge,
 * re-encode as JPEG q90 with mozjpeg. EXIF strip is mandatory per D-009.
 */
export async function processCaptureImage(input: Buffer | string): Promise<ProcessedImage> {
  const pipeline = sharp(input)
    .rotate() // honor EXIF orientation, then strip
    .resize(1536, 1536, { fit: "inside", withoutEnlargement: true })
    .jpeg({ quality: 90, mozjpeg: true })
    .withMetadata({}); // <-- empty options = strip all metadata

  const buffer = await pipeline.toBuffer();
  const meta = await sharp(buffer).metadata();
  return {
    buffer,
    width: meta.width ?? 0,
    height: meta.height ?? 0,
    byteLength: buffer.length,
  };
}
```

> Sharp note: `.withMetadata({})` keeps a minimal sRGB profile but strips all
> EXIF/IPTC/XMP/GPS. Verify with exiftool in the test below.

### E.9 Feature flag infrastructure

```typescript
import { createClient } from "@supabase/supabase-js";

const SUPABASE_URL = process.env.NEXT_PUBLIC_SUPABASE_URL!;
const SUPABASE_ANON_KEY = process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!;

const reader = createClient(SUPABASE_URL, SUPABASE_ANON_KEY, { auth: { persistSession: false } });

export type FlagKey = string;

export interface FlagRow {
  key: string;
  enabled: boolean;
  percent_rollout: number;
  environment: "development" | "preview" | "production" | "all";
  description: string | null;
}

const cache = new Map<string, { row: FlagRow | null; expiresAt: number }>();
const TTL_MS = 30_000;

export async function readFlag(key: FlagKey): Promise<FlagRow | null> {
  const env = process.env.VERCEL_ENV ?? process.env.NODE_ENV ?? "development";
  const now = Date.now();
  const hit = cache.get(key);
  if (hit && hit.expiresAt > now) return hit.row;
  const { data, error } = await reader.from("feature_flags").select("*").eq("key", key).maybeSingle();
  if (error) {
    cache.set(key, { row: null, expiresAt: now + TTL_MS });
    return null;
  }
  const row = (data as FlagRow | null) ?? null;
  if (row && row.environment !== "all" && row.environment !== env) {
    cache.set(key, { row: null, expiresAt: now + TTL_MS });
    return null;
  }
  cache.set(key, { row, expiresAt: now + TTL_MS });
  return row;
}

export async function isFlagEnabledForUser(key: FlagKey, userId: string | null): Promise<boolean> {
  const row = await readFlag(key);
  if (!row || !row.enabled) return false;
  if (row.percent_rollout >= 100) return true;
  if (row.percent_rollout <= 0) return false;
  if (!userId) return false;
  const hash = simpleStableHash(`${row.key}:${userId}`);
  return hash % 100 < row.percent_rollout;
}

function simpleStableHash(s: string): number {
  let h = 5381;
  for (let i = 0; i < s.length; i++) h = ((h << 5) + h + s.charCodeAt(i)) | 0;
  return Math.abs(h);
}
```
